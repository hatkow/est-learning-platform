# microCMS 導入手順（コース機能・サムネイル画像）

このサイトの「コース」（`/courses`）を **microCMS の管理画面から登録・編集**できるようにする手順です。
コラム（`docs/microcms-setup.md`）と同じ考え方で、**サムネイル画像もここからアップロードするだけ**で反映されます。

> 実装はフォールバック方式です。**環境変数を設定するまでは今まで通りサンプルコースで動作**し、
> 設定した瞬間に microCMS へ切り替わります。焦らず進めて大丈夫です。

---

## STEP 1. コースAPIを作成

コラムと同じmicroCMSサービス内に、新しくAPIを追加します（サービスドメイン・APIキーはコラムと共通で使えます）。

1. サービス管理画面で「APIを作成」→「**自分で決める**」
2. **API名**: `コース` / **エンドポイント**: `course`（← この名前を使います）
3. **APIの型**: 「**リスト形式**」を選択

## STEP 2. APIスキーマ（項目）を設定

以下の項目を追加してください（フィールドIDは**この通りの英字**にしてください。コードが参照します）。

| フィールドID | 表示名 | 種類 | 必須 | 備考 |
|---|---|---|---|---|
| `title` | タイトル | テキストフィールド | ✓ | コース名 |
| `slug` | スラッグ | テキストフィールド | ✓ | URLに使う英数字（例: `powerapps-basic`） |
| `subtitle` | 一覧用の説明 | テキストフィールド | | コース一覧カードに出る短い説明 |
| `description` | コース概要 | リッチエディタ／テキストエリア | | コース詳細ページの本文説明 |
| **`eyecatch`** | **サムネイル画像** | **画像** | | **コース一覧・詳細ページに表示。無ければ色のグラデーションで代替** |
| `thumbnailColor` | カバー色 | テキストフィールド | | `eyecatch`が無いときの背景色（例: `#1a56a0`） |
| `category` | カテゴリ | テキストフィールド | | `PowerApps` / `Power Automate` / `Power BI` / `基礎・共通` のいずれか |
| `level` | レベル | テキストフィールド | | `入門` / `初級` / `中級` / `上級` |
| `price` | 価格 | 数値 | | 円。0で無料 |
| `instructor` | 講師名 | テキストフィールド | | |
| `instructorTitle` | 講師の肩書き | テキストフィールド | | |
| `lessons` | レッスン | 複製可能フィールド（リピーター） | | 下記の子フィールドを持つ |

### `lessons`（リピーター）の子フィールド

| フィールドID | 表示名 | 種類 | 備考 |
|---|---|---|---|
| `lessonTitle` | レッスンタイトル | テキストフィールド | |
| `lessonDescription` | レッスン説明 | テキストエリア | |
| `videoUrl` | 動画URL | テキストフィールド | YouTube限定公開URL等 |
| `durationMinutes` | 所要時間（分） | 数値 | |
| `isFree` | 無料プレビュー | 真偽値 | オンにすると未受講者も視聴可 |

## STEP 3. サムネイル画像をアップロード

1. `course` APIでコースを追加（または既存コースを編集）
2. **`eyecatch`欄に画像をアップロード**（推奨サイズ: 横1280×縦720程度、16:9）
3. `slug`を入力（例: 既存のサンプルコースと差し替えるなら同じslugにする）
4. 「公開」ボタンを押す

これだけで、コース一覧のカードとコース詳細ページのヒーロー・サイドバーに画像が反映されます。

## STEP 4. 環境変数を設定（サイトに接続）

コラム用の`MICROCMS_SERVICE_DOMAIN`・`MICROCMS_API_KEY`は共通で使い、コース用に1つだけ追加します。

### Vercel（本番）の場合

Vercel のプロジェクト → **Settings → Environment Variables** に以下を追加:

| Name | Value |
|---|---|
| `MICROCMS_COURSE_ENDPOINT` | `course` |

（`MICROCMS_SERVICE_DOMAIN`・`MICROCMS_API_KEY`をまだ設定していない場合は、`docs/microcms-setup.md`のSTEP1・4も参照してください）

追加したら **Redeploy**（再デプロイ）してください。反映後、`/courses`が microCMS のコースに切り替わります。

### ローカルで試す場合

`.env.local`に追加:

```
MICROCMS_COURSE_ENDPOINT=course
```

`npm run dev` で確認できます。

---

## 困ったら

- コースが表示されない → 環境変数のスペル、`slug`の有無、コースが「公開」状態かを確認
- サムネイル画像が出ない → `eyecatch`に画像を設定しているか確認（未設定の間は`thumbnailColor`の色で表示されます）
- それでも解決しない場合は、この手順のどこで詰まったか教えてください。
