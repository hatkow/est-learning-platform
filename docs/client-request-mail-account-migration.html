ご協力のお願い（メール送信の仕組みを貴社アカウントへ）

お問い合わせ・会員登録メールの送信元が、開発側の個人アカウントになってしまっている件のご連絡です。 貴社のGoogleアカウントで作業いただく必要があるため、恐れ入りますがご協力をお願いいたします。 以前ご案内した手順とは別に、今回改めて手順一式をまとめましたので、最初からこのページの通りに進めていただければ大丈夫です。

いつもお世話になっております。

現在、サイトのお問い合わせフォーム・会員登録の通知メールは、開発側（弊社）のテスト用Googleアカウントで暫定的に動かしております。 そのため、メールの送信元が弊社担当者個人のアドレスになってしまっており、貴社からのご指摘の通り、本来あるべき状態ではありません。 あわせて、会員登録者ご本人へのサンキューメール（登録完了のお知らせ）も、今回まとめて追加いたしました。

下記の手順で、貴社（イースト株式会社）のGoogleアカウントにこの仕組みを移していただけますでしょうか。

1 Google Apps Script を新規作成

目安時間：10分

手順

  1. 貴社のGoogleアカウントでログインした状態で、script.google.com/create にアクセス（新しいスタンドアロンのApps Scriptプロジェクトが開きます。スプレッドシートは不要です）
  2. デフォルトで入っているコードをすべて削除し、下記のコードを貼り付け

貼り付けるコード

const RECIPIENT = 'ai@est.co.jp';

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const fields = data.fields || {};

  // 社内向け：通知メール
  const lines = Object.entries(fields).map(([label, value]) => `${label}：${value || '（未入力）'}`).join('\n');
  const body =
    `AI・Powerplatformスクールのサイトからお問い合わせ・登録がありました。\n\n${lines}\n\n` +
    `受信日時：${data.receivedAt || new Date().toISOString()}`;

  MailApp.sendEmail({
    to: RECIPIENT,
    replyTo: fields['メールアドレス'] || undefined,
    subject: data.subject || 'サイトからのお問い合わせ',
    body,
  });

  // 送信者本人向け：サンキューメール（会員登録時のみ、指定がある場合に送信）
  if (data.confirmTo) {
    MailApp.sendEmail({
      to: data.confirmTo,
      subject: data.confirmSubject || 'AI・Powerplatformスクールからのお知らせ',
      body: data.confirmBody || '',
    });
  }

  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}

※ 宛先は ai@est.co.jp に設定済みです。変更の必要はありません。

2 Webアプリとして公開

目安時間：5分

  1. 右上「デプロイ」→「新しいデプロイ」
  2. 種類の選択（歯車アイコン）→「ウェブアプリ」
  3. 「次のユーザーとして実行」を 「自分」、「アクセスできるユーザー」を 「全員」 に設定
    ※「Googleアカウントを持つ全員」を選ぶとサイトからのアクセスがブロックされてしまうため、必ず「全員」を選んでください
  4. 「デプロイ」をクリック → 初回はご自身のGoogleアカウントでの権限承認が必要です（画面の指示通りに許可してください）
  5. 発行された「ウェブアプリのURL」（https://script.google.com/macros/s/xxxxx/exec）をコピー
完了したら、以下を弊社にお知らせください
