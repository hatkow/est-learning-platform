2本番公開までにご確認・ご準備いただきたいこと

一般公開する前に、貴社側でのご判断・ご準備が必要な項目です。

ドメイン

要確定

現在はVercelの仮URL（est-learning-platform-mcau.vercel.app）で運用しています。

  • 本番公開には独自ドメイン（例：貴社ドメインのサブドメイン）のご準備が必要です
  • SSL証明書はドメイン設定後にVercel側で自動発行されます（追加費用・作業は不要）
  • ドメイン確定後、サイト内部の設定（環境変数）を1箇所更新する必要があります（検索エンジン向けの情報に反映されるため）

データの保存先（会員登録・お問い合わせ）

要確定

「自社でデータベースを持たない」方針で設計していますが、データの行き先は決めていただく必要があります。

  • 会員登録（メールアドレス）は、貴社が指定する外部システム（CRM等）へ転送する設計です。転送先が未設定の間は、開発用の仮の置き場に保存される状態になっており、これは本番運用には使えません
  • お問い合わせフォームは、担当者へのメール転送のみで、データの保管は行いません（変更なし）

講座動画のアップロード

要準備・オープン日を左右する可能性大

現在、全レッスンの動画は仮のサンプル動画のままです。

  • 実際の講座動画をYouTube（限定公開）へアップロードし、各レッスンのURLを差し替える作業が必要です
  • サムネイル画像は本サイトの機能ですでにアップロード対応済みです
  • オープン日を決める上で、このタスクが最も時間を要する可能性があります。必要な動画本数・撮影/編集の進捗状況を、この場でご確認いただくことをおすすめします

コンテンツ管理の運用方法

要ご相談

記事・コースの追加や更新を、今後どなたが・どう行うかの運用体制です。

  • コラム記事：microCMSの管理画面から執筆・公開が可能です（貴社メンバーの招待も可能）
  • コース情報：microCMS連携の仕組みは完成していますが、実際に使うには貴社にてmicroCMSのアカウント登録・設定が必要です
  • サイト内の管理画面（コース編集画面など）は見た目のみのモックで、実際の保存機能はまだ実装していません

その他の確認事項

ご認識合わせ
  • GitHubリポジトリは現在Public（公開）設定です。これは既にご確認いただき、問題ないとのご回答をいただいております
  • プライバシーポリシー・利用規約は暫定的な文面のため、公開前に内容の最終確認をおすすめします
  • アクセス解析（Google Analytics等）・Google Search Consoleは未設定です。導入をご希望の場合はお知らせください
