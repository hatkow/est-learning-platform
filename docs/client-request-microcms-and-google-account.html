1 コース管理画面（microCMS）のご登録

目安時間：15〜20分

なぜ必要か： 現在、講座（コース）情報はサンプルデータで動いています。今後、貴社ご自身で講座の追加・編集 （タイトル・説明文・サムネイル画像・動画URLなど）を、開発会社を介さずに行えるようにするための管理画面です。

手順

  1. microcms.io にアクセスし、無料登録
  2. 「サービス」を新規作成（サービスIDは任意。例：est-learning）
  3. 「APIを作成」→「自分で決める」で、API名「コース」・エンドポイント「course」・型「リスト形式」を選択
  4. 下記の項目（フィールド）を追加

コースAPIの項目（フィールドIDは英字のままご入力ください）

  • title（テキスト・必須）… コース名
  • slug（テキスト・必須）… URLに使う英数字（例：powerapps-basic）
  • subtitle（テキスト）… 一覧カードに出る短い説明
  • description（リッチエディタ）… コース詳細の本文
  • eyecatch（画像） … サムネイル画像（推奨サイズ：横1280×縦720程度）
  • category（テキスト）… Power Apps / Power Automate / Power BI / 基礎・共通 のいずれか
  • level（テキスト）… 入門 / 初級 / 中級 / 上級
  • price（数値）… 円。0で無料
  • instructor / instructorTitle（テキスト）… 講師名・肩書き
  • lessons（リピーター）… 子フィールド：lessonTitle / lessonDescription / videoUrl（YouTube限定公開URL）/ durationMinutes / isFree
完了したら、以下を弊社にお知らせください

2 自動送信の仕組みを、貴社のGoogleアカウントに移行

目安時間：各10分（2つ）

なぜ必要か： 現在、会員登録データの転送・お問い合わせメールの送信は、テスト用に弊社側のGoogleアカウントで動かしております。 本番運用にあたっては、データの所有権・継続性の観点から、貴社（イースト株式会社）ご自身のGoogleアカウントで 動かすことを推奨します。手順は以下のとおりです（今回渡すコードをそのまま使えます）。

2-A. 会員登録データ → スプレッドシート転送

  1. 貴社のGoogleアカウントで sheets.new を開き、新しいスプレッドシートを作成
  2. 「拡張機能」→「Apps Script」を開き、以下のコードを貼り付け
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);

  const headers = [
    '受信日時', '会社名', 'お名前', 'メールアドレス',
    '従業員規模', '興味のある分野', '部署・役職', '電話番号', 'メルマガ希望',
  ];

  if (sheet.getLastRow() === 0) {
    sheet.appendRow(headers);
  }

  sheet.appendRow([
    data.receivedAt || new Date().toISOString(),
    data.company || '',
    data.name || '',
    data.email || '',
    data.companySize || '',
    data.interest || '',
    data.department || '',
    data.phone || '',
    data.marketingOptIn ? '希望する' : '希望しない',
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
  2. 「次のユーザーとして実行」を「自分」、「アクセスできるユーザー」を「全員」に設定
  3. 「デプロイ」をクリックし、発行された「ウェブアプリのURL」をコピー

2-B. お問い合わせフォーム → メール送信

  1. script.google.com/create で新しいスタンドアロンのApps Scriptプロジェクトを作成（スプレッドシートは不要）
  2. 以下のコードを貼り付け
const RECIPIENT = 'ai@est.co.jp';

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const fields = data.fields || {};

  const lines = Object.entries(fields).map(([label, value]) => `${label}：${value || '（未入力）'}`).join('\n');
  const body =
    `AI・Powerplatformスクールのサイトからお問い合わせがありました。\n\n${lines}\n\n` +
    `受信日時：${data.receivedAt || new Date().toISOString()}`;

  MailApp.sendEmail({
    to: RECIPIENT,
    replyTo: fields['メールアドレス'] || undefined,
    subject: data.subject || 'サイトからのお問い合わせ',
    body,
  });

  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. 同じく「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
  2. 「次のユーザーとして実行」を「自分」、「アクセスできるユーザー」を「全員」に設定
  3. 「デプロイ」をクリックし、発行されたURLをコピー

※ 宛先はすでに ai@est.co.jp に設定済みです。変更の必要はありません。
